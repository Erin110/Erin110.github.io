## Update Personal Links

- Update `mailto:your-email@whu.edu.cn` in `index.html`.
- Update the GitHub link in `index.html` if needed.
- Add a public CV PDF to `files/` only after reviewing what should be public.

## Deploy To GitHub Pages

Recommended option:

1. Create a repository named `Erin110.github.io` on GitHub.
2. Push this folder to the repository's `main` branch.
3. Open `Settings -> Pages`.
4. Set `Source` to `GitHub Actions`.
5. Visit `https://Erin110.github.io` after the action finishes.

Alternative option:

1. Use any repository name, such as `homepage`.
2. Push this folder to `main`.
3. Open `Settings -> Pages`.
4. Set `Source` to `GitHub Actions`.
5. Visit `https://Erin110.github.io/homepage/`.

# Homepage Customization Checklist

This site is ready to deploy as a static GitHub Pages homepage. Fill in the items below when the information is ready.

## Required Before Sharing

- `index.html`: replace `mailto:your-email@whu.edu.cn` with a public academic email.
- `images/profile.svg`: replace with a formal portrait, preferably `profile.jpg` or `profile.png`, then update the `src` in `index.html`.
- `index.html`: replace the disabled CV button after preparing a public CV PDF.
- `files/`: place only a reviewed public CV, for example `files/Yawen_Jia_CV_public.pdf`.

## Recommended Content Updates

- `index.html` About Me: add GPA/rank only if you are comfortable making it public.
- `index.html` News: add accepted papers, research internships, awards, and application updates.
- `index.html` Publications / Research: add projects, preprints, GitHub repositories, or short research summaries.
- `index.html` Selected Awards: add scholarships, competitions, and honors.
- `index.html` Skills: refine programming languages, research tools, frameworks, and security skills.

## Optional Data File

- `data/profile.json`: mirrors the core profile information and can be used later if the site becomes data-driven.

## Privacy Notes

- Do not upload a full private resume unless you have checked phone number, ID number, exact ranking, transcripts, and certificate scans.
- Prefer a short public CV for GitHub Pages.
